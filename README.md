# ⚽ Gaffer's Notebook

**A tactical formation builder for football managers dealing with injury crises.**

Built by a suffering Tottenham Hotspur fan who needed a way to visualize tactics when half the squad is in the treatment room.

## Features

- 📊 **6 Formation Presets** - 4-3-3, 4-2-3-1, 3-4-3, 3-5-2, 4-4-2, 5-3-2
- 👥 **Squad Management** - Track player availability, injuries, suspensions
- 🎯 **Drag & Drop** - Assign players by dragging from squad to pitch
- 📈 **Tactical Analysis** - Real-time weakness detection and squad depth metrics
- 💾 **Save & Share** - Export as image or share via URL
- 📱 **Mobile Friendly** - Works on desktop, tablet, and phone

## How to Use

1. Select a formation
2. Drag players from the squad panel onto the pitch
3. Toggle player status (Available/Injured/Doubtful/Suspended)
4. View tactical analysis and add notes
5. Download as image or copy shareable link

## Tech Stack

- Pure HTML/CSS/JavaScript
- No dependencies (except html2canvas for image export)
- Single-file application
- Responsive design with Tailwind-inspired utilities
